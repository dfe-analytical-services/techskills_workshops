# Databricks Workshop: Overview

A hands-on introduction to working with Databricks at the DfE, from platform basics to migrating and automating your existing analytical processes.

* **00 Pre-workshop Materials (Databricks fundamentals)**: getting set up in Databricks and understanding the medallion architecture (Bronze, Silver, Gold and the DfE-specific Copper layer).
* **01 Coding within Databricks**: connecting Databricks to Git (Azure DevOps and GitHub), working with notebooks, standard code scripts and the SQL Editor.
* **02 Connecting to Databricks from RStudio, Positron or other IDE**: querying Databricks data from your local development environment.
* **03 Migrating existing processes**: handling processes that combine R and SQL code, and the options and approaches available for migrating existing work to Databricks.
* **04 Using Jobs & Pipelines**: chaining notebooks into scheduled, automated jobs and pipelines, and diagnosing failed runs.

Each section includes a hands-on task and a short knowledge check quiz.
